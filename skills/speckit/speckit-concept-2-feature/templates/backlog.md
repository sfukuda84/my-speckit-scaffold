# 機能候補バックログ

`docs/feature/` にまだ機能化していない候補と、意図的に採用しなかった候補を置く場所。
`speckit-concept-2-feature --backlog <ID>` で、候補を `docs/feature/NNN-<slug>.md` として機能化できる。

## 運用ルール

- 状態は **候補 / 機能化済み（docs/feature/NNN-slug.md） / 却下** のいずれか
- 候補は消さない。機能化・却下したら状態欄を書き換える。却下したものを復活させるときは、状態を「候補」に戻して理由を追記する
- 要件概要は**広く浅く**書く（カラム型・API パス・数値パラメータは書かない）
- 手で候補を足してよい。ID は既存の最大値の次から振る
- 「機能化するときに決めること」は、機能化するときのヒアリングの最初の論点になる
